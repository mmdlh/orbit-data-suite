# 机房动环系统平台实施计划

## 目标
构建一个可直接浏览的六模块机房动环监控平台，采用能源科技风、玻璃质感界面，并确保每个页面拥有不同的信息组织与丰富的数据展示。

## 实施内容
1. 建立统一设计系统：深色能源科技背景、青绿与电光蓝主色、半透明毛玻璃卡片、流光边框、悬浮反馈和克制的动态效果。
2. 制作固定顶部导航：左侧三个菜单、中央系统标题、右侧三个菜单；桌面端左右对称，移动端可横向浏览。
3. 建立六个独立页面：监控总览、动力环境、安防消防、告警管理、报表分析、系统管理。
4. 为各页面安排不同布局，并组合统计卡、状态灯、数据表格、折线图、柱状图、雷达图和饼图。
5. 使用模拟实时数据与交互筛选，让导航、视图切换、设备筛选和表格操作可用。
6. 补全每个页面的独立标题与分享描述，并检查桌面与移动端显示。

## 技术说明
- 基于现有 React 与 TanStack 路由结构，每个一级菜单对应独立地址。
- 图表采用 ECharts，折线图图例统一置顶并预留顶部间距。
- 所有色彩、阴影、渐变和玻璃效果集中定义为语义化设计变量。
- 背景视觉以本地生成的能源数据中心图像承载，不依赖外部图片。
