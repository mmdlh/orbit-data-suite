# Energy Sentinel

"做一个机房动环系统平台，6个一级菜单，1.监控总览（首页大屏，机房全景、实时告警、PUE、设备状态汇总）

2.动力环境（动力 + 环境设备，UPS、配电、空调、温湿度、漏水等实时数据、组态）

3.安防消防（门禁、视频监控、消防主机、入侵报警）

4.告警管理（实时告警、告警历史、告警策略、告警推送配置）

5.报表分析（能耗报表、历史曲线、PUE 分析、巡检报表、故障统计）

6.系统管理（用户权限、资产台账、采集配置、操作日志），要求：

能源相关科技风背景，能源相关配色为主色调，带能源风格背景图

毛玻璃半透明卡片，带流光渐变边框和hover浮起效果

顶部固定导航栏，左侧3个图标菜单+大标题居中+右侧3个图标菜单，导航栏也要有玻璃质感

每个页面布局要有差异，内容要丰富：统计数据卡片 + 多种echarts图表（折线、柱状、雷达、饼图混排）+ 数据表格 + 状态指示器

数据要有立体感和色彩冲击力，整体炫酷、现代、有科技感"
